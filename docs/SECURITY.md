# AgentHub 安全文档

## 1. 安全审计概述
- 4 轮安全审计
- 69 个问题修复
- 3 个 RCE 级漏洞封堵

## 2. SSRF 三层防御
- URL 校验（协议、主机名）
- DNS 解析校验（私有 IP 拦截）
- 重定向校验（手动跟随重定向）

## 3. MCP 命令注入防护
- 命令白名单（npx、node、python、uvx）
- Shell 元字符拦截（;、|、&、`、$()）
- 危险参数检测（python -c、node -e）

## 4. AST 沙盒隔离
- builtins 隔离（_make_safe_builtin）
- 属性访问拦截（__builtins__、__globals__、__class__）
- sys.stdout 替代（_safe_print）

## 5. 路径穿越防护
- 文件上传路径校验
- 符号链接穿越检测
- 会话目录隔离

## 6. 浏览器安全
- URL 白名单（内网地址拦截）
- 反自动化检测（playwright-stealth）
- 元素操作频率限制

## 7. 输出校验
- Pydantic 模型校验
- 反模式检测（问句拦截）
- 自动重试机制

## 8. 子进程安全模块
- 使用 Windows Job Objects 限制子进程内存与 CPU 使用，防止资源耗尽攻击
- 进程树安全终止机制，确保父进程退出时所有子进程一并清理，避免僵尸进程残留
- 子进程继承环境变量白名单隔离，防止敏感信息泄露

## 9. 代码沙盒管理器
- 多模式沙盒支持：Subprocess 沙盒（独立进程隔离）+ AST 沙盒（语法树级别执行限制）
- 超时控制机制，单次执行超时自动终止，防止死循环阻塞系统
- 输出截断保护，限制单次执行的最大输出长度，避免内存溢出

## 10. AST 安全解释器增强
- 循环迭代次数上限，防止恶意构造的无限循环 DoS 攻击
- 异步执行支持，在事件循环中安全运行用户代码，避免阻塞主进程
- 递归深度限制与表达式复杂度检查，进一步加固沙盒安全性

## 11. 缓存层安全
- Redis 连接启用密码认证，防止未授权访问缓存数据
- 内存 LRU 降级策略，Redis 不可用时自动切换本地缓存，保证服务连续性
- 缓存键命名空间隔离，防止不同会话间数据串读

## 12. 输出校验安全
- 反模式检测拦截问句、无效输出等不符合预期的 Agent 回复
- 格式合规检查确保输出符合预定义的 Pydantic Schema，拒绝非法结构
- 校验失败自动重试机制，最多重试 N 次后降级为兜底策略，保障 99.9% 格式合规率

## 13. 代码审查安全
- 规则引擎检测硬编码密码（password/secret/api_key/token 赋值模式）
- SQL 注入检测（f-string 拼接 SQL 语句）
- 命令注入检测（os.system/subprocess 调用中的字符串格式化）
- 审查评分低于阈值时自动触发自愈重试，直到代码安全合规

## 14. 测试覆盖
- 304 个后端测试
- 安全专项测试：SSRF（31）、路径穿越（18）、MCP（6）、加密（5）
- 输出校验测试（21）

## 15. CI/CD 安全
- GitHub Actions 自动化
- Ruff lint + pytest + ESLint + Bandit
- 每次 PR 自动运行
