## 一、目标

## 五、功能迁移清单

| 功能 | 当前位置 | 迁移目标 | 原位置处理 |
|------|---------|----------|-----------|
| 🔍 搜索对话 | ChatPanel header `Search` 图标 → SlidePanel | 侧边栏底部搜索框 | 删除 header 的 Search 按钮 |
| ＋ 新对话 | 原侧边栏底部「新建 Agent」→ AgentSelector | 侧边栏「＋ 新对话」按钮 | 原按钮功能移除，位置被 Agent 列表占据 |
| Agent 列表 | AgentSelector 弹窗 | 侧边栏「智能体」分组 | AgentSelector 保留用于「＋ 新对话」 |
| Agent 状态显示 | agentStore status 字段 | 侧边栏智能体列表每行的角色+状态 | ChatPanel header 不再重复显示 |
| PM 常驻 | tabStore DEFAULT_TAB | 智能体列表第一位，不可删除，不可关闭 | 从 agent 列表中排除 PM（不在其他地方重复出现） |

## 六、行为规格

### 6.1 智能体分组
- **PM 小助手**: 始终显示在列表第一位，不可删除，不在 "选择 Agent" 弹窗中出现
- **点击 agent**: 调用 `openTab(convId, name, agentId)` 新建/打开独立对话标签页
- **状态指示**: 每行右侧显示在线状态圆点（online=绿/busy=橙/offline=灰），数据来源 agentStore
- **自定义 agent**: 列表末尾动态追加，可删除
- **折叠**: 「▼ 智能体」标题行可点击折叠/展开 agent 列表
- **＋ 按钮**: hover 显示 tooltip "新建Agent"，点击打开 AgentCreator 弹窗

### 6.2 资源分组
- 整体「▼ 资源」可折叠
- 四个子类：技能 / 工具 / 知识库 / 模型，每个可独立折叠
- 每个子类右侧有「＋」按钮，hover 提示各子类名称，功能暂不做
- 子类展开后当前为空（后续补充默认内容和搜索）

### 6.3 搜索对话
- 从右上角 ChatPanel header 的 `Search` 图标迁移至侧边栏底部
- 输入关键词，过滤当前 agent 的历史对话（按名称和消息内容匹配）
- 删除 header 中的 Search 按钮
- 搜索结果展示在下方历史对话区域

### 6.4 新对话
- 「＋ 新对话」按钮复用 `.conversation-item` 样式
- 点击打开 AgentSelector 弹窗（所有 agent 可选，不含 PM）
- 选择 agent 后创建对话标签页

### 6.5 历史对话
- 仅显示**当前激活标签页**对应 agent 的对话记录
- 无历史对话时，该区域默认不显示
- 切换 agent 标签时，历史对话列表自动跟随更新

## 七、Agent 显示规则

| Agent | 智能体列表 | AgentSelector 弹窗 | 可删除 |
|-------|-----------|-------------------|--------|
| agent_pm (PM小助手) | ✅ 常驻第一位 | ❌ 不出现 | ❌ |
| agent_frontend/backend/tester/devops/designer | ✅ | ✅ | ❌ (隐藏) |
| agent_builder | ❌ 不出现 | ❌ 不出现 | ❌ |
| 自定义 agent | ✅ 列表末尾 | ✅ | ✅ |

---

## 八、不受影响的功能

- 侧边栏折叠/展开动画（`transition: width 300ms`）
- 右键菜单（置顶/归档）
- 拖拽排序（收起时禁用）
- 设置面板入口
- 移动端响应式（hamburger + overlay）
- 右侧 SlidePanel 的代码/预览面板
- 聊天区域消息发送/接收
- 输入框所有功能

---

## 九、改动文件清单

| 文件 | 改动类型 |
|------|---------|
| `Sidebar.jsx` | 重写 |
| `ChatPanel.jsx` | 移除 Search 图标按钮 |
| `App.jsx` | 可能需调整（宽度变化） |
| `global.css` | 侧边栏宽度 200→300px，收起 60px 不变，新增分组样式 |
| `agentStore.js` | 可能需要 `isPMAgent()` 判断方法 |
| `SlidePanel.jsx` | 移除 search 内容渲染（搜索面板可能不再需要） |
| `SearchPanel.jsx` | 可能需要重构或废弃（搜索功能迁移到侧边栏内） |

## 十、约束

- 不添加 🏠 工作台导航入口
- 资源子类的「＋」新建功能后续补充，本次不做
- 参考图「展示全部系列」按钮（闭眼图标）不做
- 保持现有 Coze 设计 token 不变
- 所有颜色/字号/间距使用 CSS 变量
