# AgentHub 实施计划与状态

## 目标

完成“自然语言生成工具软件、开发过程运行预览、多轮对话修改、发布链接或安装产物”的可验收演示版，并保留向生产平台扩展的边界。

## 已完成阶段

1. **基线与风险确认**：核对测试、部署、沙箱、并发和安全边界。
2. **统一工程工作区**：迁移旧 sandbox，统一生成、预览、部署所使用的目录。
3. **可观测性 API**：补齐指标、Trace、Artifact API 与前端错误恢复。
4. **多文件工程**：解析 `path=` 代码块，原子写入、文件树、Git 快照和恢复。
5. **多租户配置**：稳定设备身份；隔离 LLM、STT、HIL、质量门禁和工具开关。
6. **真实预览**：静态 Web、隔离 Vite、在线 API 调试、小程序体验二维码和 APK 边界。
7. **交付加固**：Alembic 迁移、预检 CLI/API、E2E、部署文档和验收清单。
8. **多人隔离**：会话、工程、上传、自定义 Agent、知识库、发布记录与配置按租户隔离。
9. **分布式协调**：生成租约/停止状态、调度主节点、任务原子抢占、重试状态和 WebSocket 广播迁移到 Redis/数据库。
10. **生产数据层**：PostgreSQL 独立迁移服务，S3/MinIO 文件后端，远程 Chroma，依赖锁定。
11. **身份与成本**：受信任 OIDC/OAuth2 代理身份、只读角色、独立机器令牌、实际模型 Token 日统计与配额。
12. **真实集成测试**：CI 使用 PostgreSQL、Redis、FastAPI 和真实 WebSocket 执行浏览器验收。

## 后续优先级

1. **P0 可恢复生成 Worker**：把模型生成执行从 WebSocket 所在 API 进程迁移到持久队列，并支持检查点续跑。
2. **P1 工作区共享存储**：把可变工程工作区迁移到 RWX 卷或对象存储快照，消除多主机构建的共享卷前提。
3. **P1 完整成本模型**：在模型 Token 之外统计预览容器时长、构建分钟数、网络和产物容量。
4. **P1 身份平台交付**：提供 Keycloak/Authentik 等参考部署、用户组到角色映射和管理员审计页面。
5. **P1 发布治理**：域名绑定、TLS、版本审批、审计日志、回滚策略和凭证轮换。
6. **P2 产物市场**：软件模板、版本说明、访问权限和分享统计。
