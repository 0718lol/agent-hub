# Vibe Coding 快速开发流程

适用场景：用户用自然语言描述需求，需要快速生成可运行的代码。

## 工作流程

### 第 1 步：需求确认

用一句话复述用户的需求，确认理解无误。如果需求模糊，提出 2-3 个具体的澄清问题。

### 第 2 步：方案设计

在写代码之前，简要说明：
- 技术方案（用什么框架/库/模式）
- 文件结构（需要创建/修改哪些文件）
- 关键实现思路

让用户确认方案后再动手。

### 第 3 步：代码生成

按方案生成代码。遵循以下原则：
- 代码风格与项目现有代码保持一致
- 先实现核心功能，不做过度设计
- 添加必要的错误处理（只处理真实可能发生的错误）
- 变量和函数命名清晰自解释，不写多余注释

### 第 4 步：运行验证

生成代码后，立即验证：
- 运行项目（`npm run dev`、`python -m uvicorn` 等）
- 测试核心功能是否正常工作
- 检查是否有明显的错误或警告

### 第 5 步：迭代优化

根据验证结果或用户反馈进行迭代。每次迭代前确认改动范围，避免过度修改。

## 技术栈适配

根据项目实际情况选择技术栈，常见组合：

| 场景 | 推荐技术栈 |
|------|-----------|
| Web 前端 | React + Vite / Vue + Vite / Next.js |
| Web 后端 | FastAPI / Express / Flask |
| 数据处理 | Pandas + Jupyter / Polars |
| AI 应用 | LangChain / OpenAI SDK / Anthropic SDK |
| 桌面应用 | Electron / Tauri |
| 移动端 | React Native / Flutter |

## 注意事项

- 不要引入项目中没有的新依赖，除非必要且用户同意
- 生成的代码应该能直接运行，不需要用户做额外配置
- 如果项目有现有模式，优先遵循现有模式
